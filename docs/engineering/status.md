# 历史实施记录（2026-10-20）

本页保留基础版本的实施证据，不表示当前开发状态。后续实现与检查以 GitHub PR、Actions 为准；当前候选版本的配置与验收入口见 [0.2.0-rc.1 交付指南](workbench-app-0.2.0-rc.1-release-and-manual-validation.md)。

日期：2026-10-20。规范工作区为当前仓库，旧源码目录保留作迁移前参考；原中文项目目录的源码索引已指向 `apps/server`、`apps/web`。

已实现并进入验证：

- 内部用户、密码凭据、外部身份与项目成员表；受控且幂等的本机初始化。
- Argon2id、本地密码登录、Spring Session JDBC、会话期限、安全版本及退出全部设备。
- 项目角色、资源实际归属校验、成员邀请与所有权转移、事务内成功审计。
- AGE SQL/Cypher 编码边界、只读自由查询及执行/结果限制。
- Workbench OIDC Java 登录和显式身份绑定代码。
- 前端登录、会话菜单、成员管理与邀请页面。

本机隔离库已创建 7 个规范测试用户、2 个测试项目，初始密码按用户要求与用户名相同；7 个用户实际登录及 31 项 HTTP 基础验收通过。原 `ontology_workbench_local` 数据库未迁移，原公网入口仍保持旧链路。

已完成原库备份和隔离恢复。恢复中发现 AGE 普通 oid 不会像 regnamespace 自动重映射，已仅在副本修复目录关联，并完整比对两个图谱的节点、关系和业务 ID。

真实 PostgreSQL / AGE 集成验证已通过：关系表与图写入共同回滚，以及引号、反斜杠、换行、中文、美元符号原样读回。Java 测试共 71 项，68 项通过、3 项按条件跳过；App 历史模板契约测试 36 项通过。

本机真实接口补充 17 项通过：查看者查询与导出、跨项目拒绝、编辑者禁止删除整个图谱、管理员亦禁止查询入口写入，以及邀请接受与退出后的权限变化。浏览器验收覆盖 4 类用户、正确回跳、CSRF 新建项目、进入图谱、退出会话、查看者操作和 390px 登录页；未发生浏览器运行时异常。
